# tg-ws-proxy-android

Легковесный Android-клиент и сервис для [tg-ws-proxy-Manager-go](https://github.com/00x61/tg-ws-proxy-Manager-go) (by `@00x61`), позволяющий запускать локальный прокси и безопасно туннелировать трафик Telegram через Cloudflare WebSocket / CDN во время замедлений и блокировок MTProto/SOCKS5.

---

## 🚀 Возможности

- **Полная мультиплатформенность бинарника**: в сборку включены скомпилированные нативные Go-библиотеки (`libtgproxy.so`) под все актуальные Android-архитектуры:
  - `arm64-v8a` (современные смартфоны)
  - `armeabi-v7a` (старые 32-битные ARM устройства)
  - `x86_64` (эмуляторы Android, хромбуки)
  - `x86` (32-битные эмуляторы)
- **Удобный и минималистичный UI**:
  - **Тумблер включения / выключения**: старт и остановка локального фонового Foreground Service в одно нажатие.
  - **Кнопка «Подключить в Telegram»**: мгновенный импорт настроек прокси прямо в приложение Telegram по официальному URI `tg://socks?server=127.0.0.1&port=1080`.
  - **Текстовое поле ввода адреса**: быстрый выбор или ручной ввод нужного WS-прокси хоста из встроенного пула доменов (`pclead.co.uk`, `offshor.co.uk`, `cakeisalie.co.uk`, `noskomnadzor.co.uk`, `lovetrue.co.uk`, `sorokdva.co.uk`, `pyatdesyatdva.co.uk`, `kartoshka.co.uk`).
- **Экран расширенных настроек**:
  - Порт локального SOCKS5-сервера (по умолчанию `1080`).
  - Тумблер автозапуска сервиса при включении устройства (`RECEIVE_BOOT_COMPLETED`).
  - Тумблер «Разрешить подключения из локальной сети» (привязка к `0.0.0.0` вместо `127.0.0.1`).
- **Надежный фоновый режим**:
  - Запуск через Android Foreground Service с уведомлением и статусом подключения.
  - Автоматический контроль дочернего нативного Go-процесса и корректное завершение при выключении тумблера.

## 🛠 Как это устроено под капотом

1. **Go Core**:
   Оригинальный движок прокси взят из репозитория [00x61/tg-ws-proxy-Manager-go](https://github.com/00x61/tg-ws-proxy-Manager-go).
   Бинарник скомпилирован кросс-компилятором Go под Linux/Android с поддержкой NDK-окружения и упакован в виде разделяемых библиотек `libtgproxy.so` в директории `jniLibs/`.
2. **Android Wrapper**:
   Приложение распаковывает и запускает нативный бинарник внутри своего защищенного приватного каталога (`/data/data/com.anen.tgwsproxy/lib/libtgproxy.so`).
3. **SOCKS5 <-> WebSocket Proxy**:
   Приложение поднимает локальный SOCKS5-сервер на `127.0.0.1:1080`. Клиент Telegram отправляет трафик в этот локальный порт, а сервис упаковывает пакеты в защищенные WebSocket-соединения с TLS к указанному CDN/Cloudflare узлу, обходя цензуру провайдера.

## 📦 Сборка и установка

### Готовые APK
В релизах доступны собранные пакеты:
- `app-release.apk` — оптимизированная релизная версия с ProGuard/R8.
- `app-debug.apk` — отладочная версия.

### Сборка из исходников
Для сборки требуется Android SDK (API 34) и Gradle:
```bash
./gradlew assembleRelease
```
Результат сборки появится в `app/build/outputs/apk/release/app-release.apk`.
